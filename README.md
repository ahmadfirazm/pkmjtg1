# Puskesmas Jatigede — GitHub Pages build

This folder is a static HTML build generated from the PHP project.

- `index.html` is the homepage.
- Internal PHP pages were rendered to `.html`.
- CSS, JS, favicon, and assets are included.
- The original PHP project should be kept separately for deployment to a PHP-capable `.go.id` server.

Note: PHP-only functionality such as server-side forms/login is not executable on GitHub Pages.
